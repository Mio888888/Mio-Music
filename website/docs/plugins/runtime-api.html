// Runtime API

运行时 API

插件运行在 QuickJS 里，宿主在脚本之前注入一小组全局对象。这一页列出能用的全部东西，以及每一项的限制。

全局对象一览

名称说明
cerumusic宿主 API：网络、存储、配置、工具函数。本页的主角。
consolelog、info、debug、warn、error 写入插件日志；group 系列是空操作。
fetch基于 cerumusic.request 的最小实现：返回 { ok, status, headers, json(), text() }。
setTimeout / clearTimeout可用，同时最多 128 个待触发的定时器。setInterval 调用会直接抛错。
atob / btoaBase64 编解码。btoa 只接受 Latin-1 字符。
Buffer.from精简版：Buffer.from(string | array, 'base64' | 'hex')，返回带 toString('hex' | 'base64') 的 Uint8Array。
window、global、globalThis都指向全局对象。
module、exportsCommonJS 导出入口。
require不可用，调用即抛错「当前宿主不支持 require」。

标准的 ECMAScript 内建对象（Promise、JSON、Math、Date、Map、RegExp、encodeURIComponent 等）由 QuickJS 提供。没有 DOM、XMLHttpRequest、localStorage、文件与进程接口。

cerumusic.request

const res = await cerumusic.request(url, options);
// res = { statusCode, headers, body }

发起一次 HTTP(S) 请求，返回 Promise。也支持回调写法：cerumusic.request(url, options, (err, res) => {})。

options

字段说明
method默认 GET。
headers对象，值必须是字符串，最多 64 个。
body字符串；传对象时会被序列化为 JSON 字符串，但不会自动设置 Content-Type，请自己加。最大 1 MiB。
timeout毫秒，默认并且最大为 15000。同时受单次调用 30 秒总时限约束。
responseType设为 'base64' 时，body 是响应字节的 Base64 字符串（用于二进制内容）。

返回值

字段说明
statusCodeHTTP 状态码。非 2xx 不会抛错，请自己检查。
headers响应头，键为小写。
body响应体。如果内容是合法的 JSON，已被解析成对象 / 数组 / 数字，否则是字符串。
body 可能已经被解析过 因为 body 会被自动 JSON.parse，一个内容恰好是 123 或 "abc" 的响应会变成数字或字符串。写一个小工具来统一处理，内置插件里都有类似的写法： 
function json(res) {
  let body = res.body;
  if (typeof body === 'string') {
    try { body = JSON.parse(body); } catch (_) { throw new Error('服务器返回的不是 JSON'); }
  }
  return body;
}

地址与失败

  • 只允许 http / https，地址长度不超过 8192 字符，不能包含用户名密码（https://user:pass@host）。不合法的地址让 Promise reject，错误是「地址只支持无用户信息的 HTTP/HTTPS」。
  • 最多跟随 5 次重定向；响应自动解压 gzip 与 brotli。
  • 网络失败、超时、响应过大、请求次数超限，都会让 Promise reject（错误信息是宿主的固定文案，不含 URL）。

cerumusic.requestAll

const replies = await cerumusic.requestAll([
  { url: urlA, options: {} },
  { url: urlB, options: { headers: { Accept: 'application/json' } } },
]);
for (const r of replies) {
  if (r.error) { /* 这一个失败了 */ continue; }
  const { statusCode, body } = r.response;
}

并发发出多个请求（同时最多 8 个），结果按输入顺序返回，每一项是 { response } 或 { error }，Promise 本身不会因单个请求失败而 reject。一次最多 24 项，并且每一项都计入这次调用的请求次数上限。适合「先取列表，再并发取每一项的详情」这类场景，比串行 await 快得多。

cerumusic.storage

cerumusic.storage.set('session', { token, expires: Date.now() + 3600e3 });
const s = cerumusic.storage.get('session');   // 没有时是 undefined
cerumusic.storage.remove('session');

每个插件私有的持久化键值存储，同步调用。典型用途是缓存登录会话。

  • 值会被序列化为 JSON，读取时还原；undefined 存为 null。
  • 键不能为空，最长 128 个字符。整个存储序列化后不得超过 256 KiB，超过时 set 抛错。
  • set 会立即交给宿主持久化；它跨调用、跨应用重启保留。
  • 存储同样不是加密的。过期的令牌记得清理，缓存键里最好带上能让缓存失效的信息（例如服务器地址与密码的哈希），这样用户改了配置就不会读到旧会话。

cerumusic.config

用户在「配置」表单里填的值，一个普通对象，键就是 config 里声明的 key。没有声明表单时是 {}。始终防御性地读取：

const c = cerumusic.config || {};
const baseUrl = String(c.baseUrl || '').trim();
if (!baseUrl) throw new Error('请先在插件“配置”中填写服务器地址');

用户可能还没填，也可能填了带空格或尾部斜杠的值。校验并规范化它们是你的责任。

cerumusic.utils

crypto

函数说明
md5(text)返回 32 位小写十六进制。Subsonic 令牌认证用它。
sha1(text)返回 40 位小写十六进制。
aes128EcbHex(text, key)AES-128-ECB、PKCS7，key 是 16 个字符的文本，返回大写十六进制。
aes128EcbBase64(op, data, keyHex)AES-128-ECB、PKCS7。op 为 'encrypt'（data 是文本，返回 Base64）或 'decrypt'（data 是 Base64，返回文本）；keyHex 是 32 位十六进制。输入非法时抛错。
aesEncrypt、rsaEncrypt、randomBytes未实现，调用会抛错。需要随机数请用 Math.random()。

buffer

cerumusic.utils.buffer.from(data, encoding) 与 bufToString(buffer, encoding)，与全局 Buffer.from 同源，encoding 可为 'base64' 或 'hex'。

lyric

函数说明
validTtml(text)判断一段文本是不是可解析且至少包含一行有内容的 TTML（不超过 2 MB）。在返回 ttml 之前用它自检。
